# Ghoster-tool

# instalação

# para debian

```bash
sudo apt update -y && sudo apt upgrade -y && sudo apt install python3 python2 python3-pip git -y && git clone https://github.com/ilzacoelhomt73-cmyk/Ghoster-tool.git && cd Ghoster-tool && pip install -r requirements.txt --break-system-packages && python3 ghoster.py
```
# para termux

```bash
pkg update -y && pkg upgrade -y && pkg install python2 python git -y && git clone https://github.com/ilzacoelhomt73-cmyk/Ghoster-tool.git && cd Ghoster-tool && pip install -r requirements.txt && python ghoster.py
```
